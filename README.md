## The entry

> WARNING: Do not step on butterflies. We accept no liability for altered elections, unborn grandparents, or Tuesdays.

A straight-faced safety notice, as printed on the machine itself: the
butterfly effect stated as a liability waiver, with the consequences
escalating from history itself down to a weekday.

## Run it

Requires Python 3 (standard library only):

```sh
python3 main.py
```

This writes the warning label to `/output/entry.txt` (UTF-8, no trailing
newline, 116 characters — inside the competition's 1–120 character gate).
